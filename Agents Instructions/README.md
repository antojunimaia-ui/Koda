# Agents Instructions 🤖

Esta pasta é o centro de inteligência para o desenvolvimento do Koda AI via Inteligência Artificial.

## 🎯 Ponto de Entrada Único

Diferente de outros projetos que usam arquivos dispersos, o Koda centraliza todo o conhecimento técnico em um único manual: **`AGENT.md`**.

## 🚀 Como Iniciar o Onboarding de um Agente

Sempre que você usar uma nova IA (Claude Code, Antigravity, Codex, etc.) para trabalhar neste repositório, instrua-a da seguinte forma:

> "Leia o arquivo `Agents Instructions/AGENT.md` para entender a arquitetura técnica, as regras de IPC e os padrões de interface (Tailwind 4) do Koda AI antes de começar qualquer tarefa."

## 🏗️ Conteúdo do Manual

O manual `AGENT.md` cobre:

- **Visão Geral**: Stack tecnológica (Electron + React 19 + TypeScript).
- **Diretrizes Técnicas**: Onde criar 'Tools', como usar os contratos de IPC e padrões CSS.
- **Modos de Operação**: Diferença crucial entre os modos Fast e Planner.
- **Governança de Código**: Licença BSD-3-Clause e Conventional Commits.
